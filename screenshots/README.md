# Screenshots (placeholder)

The catalog needs at least one screenshot, saved with qFlipper's screenshot
button and left exactly as qFlipper writes it (512x256 PNG; the catalog
tooling rejects other sizes, including a plain 128x64 image). None are in
the repo yet.

`catalog/manifest.yml` expects these three files; change the list there if
you take a different set:

- `ss0.png`: a question with an answer highlighted (this is the catalog preview)
- `ss1.png`: the pool menu (Practice Exam, Study by Topic, Review Missed, ...)
- `ss2.png`: an exam result, or a question with the correct answer revealed

Delete this file once the screenshots are in place if you prefer; nothing
depends on it.
